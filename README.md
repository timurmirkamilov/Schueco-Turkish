# Schüco Türkçesi — Telegram Mini App (TMA)

Мини-приложение Telegram для цеха светопрозрачных конструкций и фасадных систем Schüco: изучение профессионального турецкого языка с озвучкой и управлением карточками.

## 🚀 Возможности
- **32 профильные фразы и термина**:
  - *Контроль качества и дефекты* (зазоры, уплотнители, углы, отклонения геометрии, брак).
  - *Профили и фурнитура Schüco* (термомосты, сухари, штапики, скрытые петли AvanTec, импосты, ригели).
  - *Общение с инспектором* (акты, допуски, сверка с чертежами, исправление замечаний).
- **Нативная турецкая озвучка**: использование браузерного SpeechSynthesis API (`tr-TR`) в одно касание.
- **Интеграция с Telegram WebApp**:
  - Поддержка тем Telegram (светлая/тёмная палитра через CSS-переменные).
  - Тактильная отдача (Telegram Haptic Feedback) при нажатии кнопок.
- **Два режима работы**:
  - *Цеховой словарь / Обучение*: карточки с транскрипцией русскими буквами, озвучкой, кнопками «В конец списка» и «Запомнил!».
  - *Управление списком*: кнопки «В самый верх» (для повторения) и «В самый низ» (для выученного), тумблер статуса.
- **Поиск и фильтры**: мгновенная фильтрация по категориям и тексту (турецкий / русский).
- **Сохранение прогресса**: данные сохраняются в `localStorage`.

## 📦 Запуск и тестирование
1. **Локальный просмотр**: просто откройте `index.html` в любом современном браузере.
2. **В Telegram WebApp**:
   - Разместите `index.html` на любом HTTPS-хостинге (GitHub Pages, Cloudflare Pages, Vercel или ngrok).
   - В Telegram через `@BotFather` создайте команду или WebApp (`/newapp`) и укажите URL вашего сайта.
